# Universal Prompt — Visual Book Note Long PNG

你现在要为一本书制作一张『图书笔记超长竖图』，最终交付 PNG 图片。

书名：
『【替换成书名】』

严格执行以下流程：

『理解书籍并压缩内容 → 建立本书专属视觉语言 → 一次写完整 HTML/CSS → poster.py 渲染并审计 → 看总览图与手机缩略图 → 集中修订复验 → 交付 PNG』

## 硬规则

1. 禁止直接用生图模型生成最终长图。
2. 书名、作者、英文、副标题、编号、标签、正文全部必须是真实 HTML/CSS 文本。
3. 生图模型最多只能生成无文字插画素材。
4. 手机阅读优先，所有文字的计算字号至少 70 CSS px，包括英文、标签、图注、来源、页码、数字单位与生成编号；正文优先 70–110px。不能用缩放绕过字号下限。
5. 最终 PNG 可到约 30000px 高（默认 2x 导出时约 15000 CSS px），不设硬性长度目标。新增高度用于大字、图解、留白、转场和精选内容，不用于堆字或固定高度凑长度。
6. 一句话大部分文字保持正常舒适字号，只允许放大 1 个最关键的词或短语。
7. 区域编号 01 / 02 / 03 ... 要足够大，成为视觉元素。
8. 尽量取消硬直角矩形。卡片、网格、大章节区块优先完整圆角。
9. 大章节块上下必须留白，四个圆角完整露出；相邻章节块保持明显距离。
10. 配色可以大胆，但对比度与可读性永远优先。
11. 每本书重新决定视觉概念与版式结构，禁止机械复制上一张图。
12. 完成后必须查看整张 PNG 再交付。
13. **字体按角色混排，一册使用 5–10 款开源字体**（SIL OFL / CC0 / IPA 等可自由嵌入再分发的许可）。给每款分配明确角色，例如：正文、标题、书名与大词、序号、引文、标签、趣味强调各用一款；同一角色不混用。所有字体用 `@font-face` 相对路径本地嵌入，`font-display:block` + `document.fonts.ready` 保证字体就绪后才截图；不得依赖未授权、未安装或联网 CDN 字体。
14. **图内不写来源署名与制作说明**。"据某官网整理""本图不改写为教条口号""示例为转写非逐字对话""关于这一版/字体署名"这类句子一律不进图；来源边界、归属区分、许可记录写进随附的 sources 记录与验证文件，供复查不进成品。图内只保留书本身的内容与必要版本信息（书名、作者、译者）。
15. **句尾不用句号**：全篇可见文案以逗号收尾，句号（。）为 0（剥掉标签与 CSS 后对可见文本程序断言）。
16. **每个核心判断区块配贴合该章内容的无字 SVG 场景**（人物动作、关系结构、过程示意、空间隐喻任选），不做装饰性重复母题；同一画面类型全图不重复超过两次。

## 内容

优先依据用户提供的原书全文核对观点、案例、数据与限定条件，不拿书评代替原著；只做摘要转化，不整段搬运原文。先完整理解，再至少精简一轮。默认只保留：

- 1 个顶部钩子 / 推荐语
- 4–8 个核心观点
- 1 组行动清单 / 关键提醒
- 1 个结尾收束

每个观点优先 1–3 句短句。低价值解释直接删。

目标：『一眼能读、停下来能想、滑过去有节奏』。

## 句内字号反差

错误：整句话全部放大。

正确：

『真正稀缺的从来不是时间，而是你的』保持正常主字号；只把『注意力』放大 2–3 倍，并给关键词独立留白。

## 视觉语言

综合吸收：

- Apple：克制、焦点、留白
- Claude：现代网页的信息层级、圆角容器
- NHK《Design Ah! / Layout Song》：对齐、留白、尺度突变、重排、通过空间关系表达主次

注意：不要把 NHK 理解为『红色 + 竖排 + 日本风』。真正应该学习的是：相同元素通过对齐、位置、大小、间距变化，产生新的阅读顺序和视觉节奏。

每张长图至少采用 3 种不同内容场景，例如：

- 英雄区
- 大词独占
- 对照
- 时间线 / 路径
- 结构图 / 圆环 / 阶梯
- 不等大模块群
- 安静留白转场
- 行动清单

禁止 6–8 个章节全部长成同一张卡片。

## 字号参考（1440 CSS px 宽）

以下均为 HTML 母版的 CSS 字号，不是导出 PNG 的像素字号；默认 2x 导出不会降低 70px 下限。最小号提到 70px 后，最大号同步放大 50% 以保持尺度反差：

- 书名：180–285px
- 大编号：225–270px
- 章节标题：96–120px
- 主句：70–90px
- 句内关键词：165–235px
- 卡片标题：70–80px
- 正文 / 辅助文字：70–110px

即使用 `em`、`rem`、百分比或继承，计算字号也不能低于 70px。空间不够时精简、换行、改布局或增加高度，不能恢复极小字。

## 圆角与留白

- 小卡片圆角建议 20–36px
- 大章节岛建议 44–72px
- 模块间距建议 16–32px
- 大章节岛之间建议 64–120px
- 大块不要贴画布上下边缘

## HTML

优先输出单文件 HTML。

要求：

- 所有文字可选择、可复制
- 使用 CSS Grid / Flex 精确对齐
- 字体用 `@font-face` 本地嵌入 5–10 款开源字体并按角色分工，不依赖联网 CDN
- 不写超大固定 min-height，避免 PNG 底部空白
- 大章节区块完整圆角
- 装饰元素不能盖文字
- 页面内置『一键导出 PNG』按钮

可使用 html2canvas 作为用户侧导出方案；自动化最终 PNG 一律使用 `scripts/poster.py`，不要依赖用户侧导出按钮。

## 渲染

运行 `python3 scripts/poster.py book.html --outdir out`，一次生成 PNG、字号与排版审计、区块裁图、总览图及手机缩略图。

渲染器在同一浏览器会话中按 6000 CSS px 切片，再无损拼接；默认 1440 CSS px 宽、2x 导出。约 30000px 指最终 PNG 高度，不是 CSS 高度。

禁止：超长页直接 `full_page=True`（可能出现黑带）；PDF 分页后再拼 PNG；固定高度凑长度。

## 完整 QA

文字：
- 书名、作者、英文、副标题准确
- 没有乱码、错字、漏字
- 浏览器计算后的最小字号 ≥70px，包含来源、页码、图注与生成编号；`underFloorPx=0`，任何 `T-MIN-FONT` 都必须修复
- 没有整句话全部巨大化
- 全篇可见文案句号（。）为 0，句尾只用逗号
- 图内无来源署名、无制作说明类句子
- 每个核心判断区块有贴合内容的 SVG 场景，且画面类型不重复

版式：
- 手机缩略状态下层级清楚
- 大编号足够明显
- 对齐关系明确
- 留白真正参与分组
- 不连续复制同一章节结构
- 没有『丑、散、空、挤』

圆角：
- 四角完整
- 大块上下有外部留白
- 相邻模块不贴死

色彩：
- 对比度足够
- 强调色不过量

PNG：
- 完整
- 无底部大段空白
- 无裁切
- 无重复接缝 / 断层 / 错位
- 文字清晰

如果用户说『重新设计』『重来』『完全重构』，禁止在旧版基础上小修或简单等比放大。重新从原书内容、视觉隐喻、阅读顺序、版式场景开始设计；旧版另存保留。

最终优先直接交付 PNG 的可点击下载链接。不要只返回本地文件路径。
