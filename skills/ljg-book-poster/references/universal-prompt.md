# Universal Prompt — Visual Book Note Long PNG

你现在要为一本书制作一张『图书笔记超长竖图』，最终交付 PNG 图片。

书名：
『【替换成书名】』

严格执行以下流程：

『理解书籍 → 生成完整内容 → 精简内容 → 建立本书专属视觉语言 → HTML/CSS 精准排版 → 一键 PNG 导出 → 浏览器整页渲染 PNG → 完整视觉 QA → 交付 PNG』

## 硬规则

1. 禁止直接用生图模型生成最终长图。
2. 书名、作者、英文、副标题、编号、标签、正文全部必须是真实 HTML/CSS 文本。
3. 生图模型最多只能生成无文字插画素材。
4. 手机阅读优先，所有主字号要比普通网页更大一档。
5. 长图可以更长，但新增高度用于留白、节奏、插图、视觉转场和精选内容，不用于堆小字。
6. 一句话大部分文字保持正常舒适字号，只允许放大 1 个最关键的词或短语。
7. 区域编号 01 / 02 / 03 ... 要足够大，成为视觉元素。
8. 尽量取消硬直角矩形。卡片、网格、大章节区块优先完整圆角。
9. 大章节块上下必须留白，四个圆角完整露出；相邻章节块保持明显距离。
10. 配色可以大胆，但对比度与可读性永远优先。
11. 每本书重新决定视觉概念，禁止机械复制上一张图。
12. 完成后必须查看整张 PNG 再交付。

## 内容

先完整理解，再至少精简一轮。默认只保留：

- 1 个顶部钩子 / 推荐语
- 4–8 个核心观点
- 1 组行动清单 / 关键提醒
- 1 个结尾收束

每个观点优先 1–3 句短句。低价值解释直接删。

目标：『一眼能读、停下来能想、滑过去有节奏』。

## 句内字号反差

错误：整句话全部放大。

正确：

『真正稀缺的从来不是时间，而是你的』保持正常主字号；只把『注意力』放大 2–3 倍，并给关键词独立留白。

## 视觉语言

综合吸收：

- Apple：克制、焦点、留白
- Claude：现代网页的信息层级、圆角容器
- NHK《Design Ah! / Layout Song》：对齐、留白、尺度突变、重排、通过空间关系表达主次

注意：不要把 NHK 理解为『红色 + 竖排 + 日本风』。真正应该学习的是：相同元素通过对齐、位置、大小、间距变化，产生新的阅读顺序和视觉节奏。

每张长图至少采用 3 种不同内容场景，例如：

- 英雄区
- 大词独占
- 对照
- 时间线 / 路径
- 结构图 / 圆环 / 阶梯
- 不等大模块群
- 安静留白转场
- 行动清单

禁止 6–8 个章节全部长成同一张卡片。

## 字号参考（1440px 宽）

- 书名：96–150px
- 大编号：130–180px
- 章节标题：54–76px
- 主句：40–56px
- 句内关键词：88–150px
- 卡片标题：30–40px
- 正文 / 辅助文字：26–34px
- 元信息：18–24px，严格少用

## 圆角与留白

- 小卡片圆角建议 20–36px
- 大章节岛建议 44–72px
- 模块间距建议 16–32px
- 大章节岛之间建议 64–120px
- 大块不要贴画布上下边缘

## HTML

优先输出单文件 HTML。

要求：

- 所有文字可选择、可复制
- 使用 CSS Grid / Flex 精确对齐
- 字体优先使用系统 CJK 字体栈
- 不写超大固定 min-height，避免 PNG 底部空白
- 大章节区块完整圆角
- 装饰元素不能盖文字
- 页面内置『一键导出 PNG』按钮

可使用 html2canvas 作为用户侧导出方案；自动化渲染优先使用 Playwright + Chromium 的 full-page screenshot。

## 渲染

首选：浏览器整页截图。

只有整页截图失败时，才退回固定 CSS 像素坐标分段截图 + 无损拼接。

禁止：PDF 分页 → PNG → 拼接。

## 完整 QA

文字：
- 书名、作者、英文、副标题准确
- 没有乱码、错字、漏字
- 没有大量小字
- 没有整句话全部巨大化

版式：
- 手机缩略状态下层级清楚
- 大编号足够明显
- 对齐关系明确
- 留白真正参与分组
- 不连续复制同一章节结构
- 没有『丑、散、空、挤』

圆角：
- 四角完整
- 大块上下有外部留白
- 相邻模块不贴死

色彩：
- 对比度足够
- 强调色不过量

PNG：
- 完整
- 无底部大段空白
- 无裁切
- 无重复接缝 / 断层 / 错位
- 文字清晰

如果用户说『重来』『完全重构』，禁止在旧版基础上小修。重新从书籍内容、视觉隐喻、阅读顺序、版式场景开始设计。

最终优先直接交付 PNG 的可点击下载链接。不要只返回本地文件路径。
