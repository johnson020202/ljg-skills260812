# Changelog — ljg-book-poster

本技能按语义化版本更新；每个发布版本在仓库打 git tag，历史版本可随时
`git checkout <tag>` 完整取回，旧内容永不覆盖丢失。

## v3.1.0 — 2026-10-19

中文排版与图形升级（用户实测反馈驱动）：

- **禁止孤字行**：折行文本末行只剩 1 字即 P2。`audit.js` 的 `T-WIDOW`
  重写（原 `fontSize<=64` 守卫在 70px 下限下失效）：任意长度末行 1 字、
  正文末行 2 字都拦截，上限 110px 放行英雄词。实测确认：真孤字必拦截、
  单行短词不误报；`text-wrap:pretty` 有帮助但对 CJK 连续字非保证，
  渲染后检测才是闸门。骨架全局启用 `text-wrap:pretty`。
- **每章创意 SVG 强化**：每个核心判断区块一枚专属无字图形，
  画面类型全图不重复（本册实测：天平水滴、韦恩交集、房中有心、
  拱桥节点、破土幼苗、绳穿环、金缮碗、圆桌、进度打点、日出）。

## v3.0.0 — 2026-10-19

阅读体验大修（由用户实测反馈驱动）：

- **字号下限 32px → 70px**：`audit.js` 的 `T-MIN-FONT` 按 70px 判 P1；
  报告字段 `under32px` 更名 `underFloorPx`；自检基线同步。
- **最大字号随最小号同步 +50%**：书名 180–285px、关键词 165–235px、
  章节编号 225–270px，保持尺度反差。
- **默认字体改为 5–10 款开源字体按角色混排**：霞鹜文楷 R/M（SIL OFL，
  正文/标题）、得意黑斜体（SIL OFL，书名/大词/序号）、汇文明朝体（CC0，
  引文）、霞鹜新晰黑（IPA，现代辅助）、霞鹜马克黑（SIL OFL，趣味强调）。
  新增 `scripts/fetch_fonts.sh`：从各上游 release 下载并 SHA-256 校验。
  骨架 `poster-skeleton.html` 重写为六字体角色映射。
- **图内禁止来源署名与制作说明**："据某官网整理""示例为转写""关于这一版"
  类句子不进成品，归属区分只写入随附 sources/verification 记录。
- **句尾禁用句号**：全篇可见文案以逗号收尾，句号数程序断言为 0。
- **按书定制排版**：新增章节→排版选择映射（章节地图、时间线、引文场景、
  一词独占等），至少 3 种场景，连续 5 区块不得同网格，章节名必须可核验。
- **每个核心判断区块配贴合内容的无字 SVG 场景**，同一画面类型不重复超过两次。

## v2.0.0 — 2026-10-17

流水线重写（commit `1300889`）：

- 一条命令 `poster.py`：渲染 + 审计 + 区块裁图 + 总览图 + 缩略图。
- `render_png.py`：CDP 切片截图绕开 Chrome 16384px 上限，消除超长页黑带。
- `audit.js`：结构化排版审计（T-UNIT-WRAP / T-KEY-BREAK / T-WIDOW /
  C-CONTRAST / SECTION-GAP / L-FIXED / T-MIN-FONT 等），替代肉眼逐块找错。
- `contact_sheet.py`：总览图一次看全，消除历史"40 次盲裁质检"耗时。
