# Changelog — ljg-book-poster

本技能按语义化版本更新；每个发布版本在仓库打 git tag，历史版本可随时
`git checkout <tag>` 完整取回，旧内容永不覆盖丢失。

## v3.3.0 — 2026-10-19

整合来源：`origin/book-poster-v3.3.0-windows-qa`（`cbf877db3ee194f6748b99293d317fb8d33b308e`）。保留其四书实践中的产品要求，以下是与 reliability 修复整合后的实际契约。2026-10-20 随集合 1.21.0 发布，标签 `v3.3.0`；平台验收以对应提交的 CI 结果为准。

- **章节编号去重**：同一个章节标题组合只留一次章号；大数字旁用英文主题标签，不重复“第 N 章”。`T-CHAPTER-DUP` 对标记标题结构给出 P2 提示，不全图去重数据或目录编号。
- **汇文字形 QA**：风险字集合为 `让药继赞钟钥认讲论证铁`。audit 输出按字体声明／显式标记限定的 `huiwenReview` 候选，不声称自动识别实际字形；固定字体版本的 120px 字符网格仍需人工复核。引用、专名不能为避字而自动改写。
- **真正默认 1080 输出**：`poster.py` 与 `render_png.py` 均默认 `--width 1440 --scale 0.75`；显式 `--scale 2` 保留 2880。布局与有效字号下限仍是 1440 CSS / 70 CSS，`--thumb-width` 独立保持 440。文件体积收益依样本而异，不承诺固定比例。
- **Windows 适配**：按环境目录发现 Chrome/Edge，保留 `CHROMIUM_PATH` 严格覆盖与 Playwright 配套浏览器优先级；QA 标签增加雅黑和随仓文楷后备；文本文件及 CLI 标准流统一 UTF-8。
- **安全发布边界**：POSIX 保留 generation 单指针切换；Windows 使用普通文件、标准库字节锁、私有 staging、备份及异常回滚，不需要 symlink 权限。Windows 多文件更新不具备 crash atomic 保证；原生运行须由 Windows CI 单独验证。
- **不移植无界解压**：保留 1.6 亿像素预算、PNG 解码检查、设备像素分片、单次 audit、主图派生 QA、旧产物保护，不设置全局 `Image.MAX_IMAGE_PIXELS = None`。
- **`text-wrap:pretty`**：有帮助但不是 CJK 孤字保证，现有渲染后 `T-WIDOW` 检查保持。

## v3.2.0 — 2026-10-19

参考图结构实验（用户投喂优秀长图，学习其"清晰完整"感）：

- **完整章节骨架模式**（可选）：CSS 实体书封（竖排书名/题签/印章/书脊）
  → 全书章节地图（已核目录分组）→ 每章四层（章号水印+标题+副标、
  粗体引导词要点×2–4、公版逐字核对的引用卡、专属 SVG）→ 收束大字。
  信息密度来自"每章层次做全"，与判断链模式可混用。
- **渲染器实测坑入档**：flex+writing-mode 竖排列会丢失（改绝对定位逐列）；
  金红低对比（红底用近白主文字）；nowrap 长机构名撑破 grid（手动断行）；
  新格式首版允许 5–7 轮调试并记录原因。
- 经《天之子李世民》1080 全图验证：P1/P2/P3=0、孤字 0、
  两处引用卡与维基文库公版逐字核对通过。

## v3.1.0 — 2026-10-19

中文排版与图形升级（用户实测反馈驱动）：

- **禁止孤字行**：折行文本末行只剩 1 字即 P2。`audit.js` 的 `T-WIDOW`
  重写（原 `fontSize<=64` 守卫在 70px 下限下失效）：任意长度末行 1 字、
  正文末行 2 字都拦截，上限 110px 放行英雄词。实测确认：真孤字必拦截、
  单行短词不误报；`text-wrap:pretty` 有帮助但对 CJK 连续字非保证，
  渲染后检测才是闸门。骨架全局启用 `text-wrap:pretty`。
- **每章创意 SVG 强化**：每个核心判断区块一枚专属无字图形，
  画面类型全图不重复（本册实测：天平水滴、韦恩交集、房中有心、
  拱桥节点、破土幼苗、绳穿环、金缮碗、圆桌、进度打点、日出）。

## v3.0.0 — 2026-10-19

阅读体验大修（由用户实测反馈驱动）：

- **字号下限 32px → 70px**：`audit.js` 的 `T-MIN-FONT` 按 70px 判 P1；
  报告字段 `under32px` 更名 `underFloorPx`；自检基线同步。
- **最大字号随最小号同步 +50%**：书名 180–285px、关键词 165–235px、
  章节编号 225–270px，保持尺度反差。
- **默认字体改为 5–10 款开源字体按角色混排**：霞鹜文楷 R/M（SIL OFL，
  正文/标题）、得意黑斜体（SIL OFL，书名/大词/序号）、汇文明朝体（CC0，
  引文）、霞鹜新晰黑（IPA，现代辅助）、霞鹜马克黑（SIL OFL，趣味强调）。
  新增 `scripts/fetch_fonts.sh`：从各上游 release 下载并 SHA-256 校验。
  骨架 `poster-skeleton.html` 重写为六字体角色映射。
- **图内禁止来源署名与制作说明**："据某官网整理""示例为转写""关于这一版"
  类句子不进成品，归属区分只写入随附 sources/verification 记录。
- **句尾禁用句号**：全篇可见文案以逗号收尾，句号数程序断言为 0。
- **按书定制排版**：新增章节→排版选择映射（章节地图、时间线、引文场景、
  一词独占等），至少 3 种场景，连续 5 区块不得同网格，章节名必须可核验。
- **每个核心判断区块配贴合内容的无字 SVG 场景**，同一画面类型不重复超过两次。
